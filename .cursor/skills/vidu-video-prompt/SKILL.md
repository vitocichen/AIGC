# Vidu 视频提示词路由

本技能只做模型选择、能力核对和子技能分流。剧本、资产、剧情保真、确认、报价、生成授权和验收仍由 `workflow` 及当前执行层负责。

## 权威来源顺序

发生差异时按以下顺序确定真实能力：

1. 当前画布节点或实际 API 返回的模型、模式和参数；
2. 当前供应商对应文档：Vidu 官方直连接口或阿里云百炼接口；
3. Vidu 官方模型文档与更新公告；
4. 阿里云《Vidu 视频生成 Prompt 指南》只指导措辞、运镜和参考描述，不覆盖接口能力。

同一商品名在不同供应商可能使用不同模型 ID、接口、字符上限和参数名，不能互抄。

## 强制选择

用户只说“用 Vidu”时，必须让用户选择：

1. **Vidu Q2**：较低成本、最长通常 10 秒；适合 Q2 Pro Fast 图生/首尾帧，或 Q2 Pro 多参考。
2. **Vidu Q3**：最长通常 16 秒、可声画同出、智能切镜和剧集专用参考模型；成本通常更高。

不得根据价格、历史节点或默认配置替用户决定。用户已明确型号时不重复问。

用户选择系列后仍需确认具体能力：

- 图生视频：一张首帧；
- 首尾帧：第一张首帧、第二张尾帧；
- 参考生视频：角色、场景、道具等多参考；
- 文生视频：无图片输入；
- 是否需要原生音频、智能切镜、多参考或最低成本。

## 子技能路由

- 用户选择 Q2、`viduq2*` 或 `vidu/viduq2*`：读取 `../vidu-q2-video-prompt/SKILL.md`。
- 用户选择 Q3、`viduq3*` 或 `vidu/viduq3*`：读取 `../vidu-q3-video-prompt/SKILL.md`。
- 型号名称与接口能力冲突时停止并指出冲突，不用相近型号静默替换。
- Seedance 任务不得读取 Q2/Q3 子技能，继续执行 `workflow` 内嵌 PART A/A9。

## 共同正文原则

Q2 和 Q3 均遵守：

- 不新增、删除、换序剧情事实，不改变角色、道具来源和用途；
- 使用准确、口语化、可见的自然语言，避免文学化心理描述；
- 先说明风格、景别、机位、构图、运镜和动态幅度，再按时间顺序写动作、环境、光线及结束状态；
- 图片引用语法服从具体供应商和接口：阿里云可使用“图1为……”，Vidu 主体调用使用 `[@主体名]`；不能同时假装两套绑定都已配置；
- 参数、参考清单、报价和分析不进入提交正文；
- 提示词定稿不等于生成授权。

## 交付记录

每个正式文件必须记录：

- 供应商：Vidu 官方 / 阿里云百炼 / 其他实际渠道；
- 精确模型 ID；
- 模型系列：Q2 / Q3；
- 生成模式；
- 时长、分辨率、画幅、音频、水印、seed 和运动幅度的真实配置；
- 输入图片/视频顺序及唯一职责；
- 只发送给模型的“提交正文”。

最终提示词使用对应子技能的模板和校验脚本，不运行 Seedance A9 校验器。
