# 本地可读执行层

本技能只替代画布的保存布局和媒体调用入口，不替代 `workflow` 的创作方法。剧本、资产设计、分段、图片提示词、Seedance 提示词、确认关口、报价、验收和采用标准与画布模式完全相同。

## 建立项目

默认 Windows 用户。若用户未指定根目录，在当前工作区建立 `作品/<作品名>/`。作品名取正式标题；未定标题时使用可读的暂定名，不使用哈希或 UUID。

首次建立以下目录，尚未进入的阶段允许目录为空，但不要提前生成占位内容：

```text
作品/<作品名>/
├─ 00_项目管理/
│  ├─ 项目状态.md
│  ├─ 制作记录.md
│  ├─ 参考素材清单.md
│  └─ 参考素材/
├─ 01_原文/
├─ 02_剧本/
├─ 03_资产设定/
│  ├─ 角色/
│  ├─ 场景/
│  └─ 道具/
├─ 04_图片/
│  ├─ 角色/
│  ├─ 场景/
│  ├─ 道具/
│  └─ 分镜/
├─ 05_视频提示词/
│  └─ 第01集/
├─ 06_视频/
│  └─ 第01集/
├─ 07_音频/
│  └─ 第01集/
└─ 08_交付/
   └─ 第01集/
```

只创建当前阶段实际需要的文件。多集项目按 `第01集`、`第02集` 继续，不把所有内容堆进单个文件。

## 文件命名

- 原文：`01_原文/原文.md`；多份来源用 `原文_来源名.md`。
- 剧本：`02_剧本/第01集_剧本.md`。
- 角色：`03_资产设定/角色/角色表.md`、`角色_<姓名>.md`。
- 场景：`03_资产设定/场景/场景表.md`、`场景_<名称>.md`。
- 道具：`03_资产设定/道具/道具表.md`、`道具_<名称>.md`。
- 采用图片：`04_图片/<类别>/<名称>_<视图或状态>_v01.<扩展名>`。
- 全片段表：`05_视频提示词/第01集/全片段表.md`。
- 正式段提示词：`05_视频提示词/第01集/第01集_场01_机舱冷开场_G01_Seedance2.5_v01.md`。Vidu 写成 `第01集_场01_场名_G01_Vidu_<模型ID>_v01.md`。
- 视频：`06_视频/第01集/第01集_场01_机舱冷开场_G01_v01.mp4`。
- 配音稿：`06_视频/第01集/第01集_配音_v01.md`，与该集视频放在一起。每段写视频文件名、说话人、类型（画内对白 / 旁白 / 无对白）、段内时间、全片时间和原文；没有对白写「无」。一段里有多句时按顺序各写一节。这份稿不发给视频模型。
- 抽帧：`06_视频/第01集/第01集_场01_机舱冷开场_G01_结尾_v01.png`。
- 音频：`07_音频/第01集/第01集_场01_机舱冷开场_G01_<角色或用途>_v01.<扩展名>`。
- 交付：`08_交付/第01集/<作品名>_第01集_<横版或竖版>_v01.mp4`。

Windows 文件名必须移除 `<>:"/\|?*` 和结尾空格/句点。名称冲突时递增 `_v02`，不得覆盖已确认或已采用版本。内部任务 ID、供应商 ID和校验值写入制作记录，不作为用户可见目录名。

## 编码与可读性

- Markdown、JSON、SRT、CSV 和清单统一使用 UTF-8；写后回读中文标题和关键字段，确认没有 `???`、`��` 或错误转码。
- 不通过可能把中文转成当前代码页的管道传递正文；必要时使用 UTF-8 文件或 Unicode 转义。
- 图片、视频和音频必须使用真实扩展名；不把二进制内容写进 Markdown。
- 不创建画布 JSON，也不仿造节点目录。引用关系在 `项目状态.md` 和正文中使用相对路径记录。

## 阶段写入

1. 原文原样保存在 `01_原文`；改编稿不得覆盖原文。
2. 剧本、资产表、全片段表和正式提示词沿用 `workflow` 的正文模板，目录布局不能成为删字段或重新排版的理由。
3. `00_项目管理/项目状态.md` 记录执行模式为“本地目录”，以及当前阶段、确认状态、采用版本和下一步。
4. `参考素材清单.md` 逐项记录真实路径、用途、控制范围和是否采用。
5. `制作记录.md` 记录模型、规格、完整提示词文件、参考顺序、报价依据、授权次数、任务状态、输出路径和错误；不写入 API Key 或访问令牌。

## 本地媒体执行

1. 只调用当前 Agent 环境真实存在的图片、视频或音频工具，不假装已配置模型。
2. 图片未指定模型时按主规则选择真实可用且满足规格的 gpt-image；视频模型必须由用户明确指定。
3. 生成前展示对象与数量、模型、规格、完整提示词、参考文件、生成次数和可靠报价，取得明确授权。
4. 参考图使用真实绝对路径传给工具；记录时改写为项目内相对路径。外部参考若需长期复用，复制到 `00_项目管理/参考素材/`，使用可读文件名并保留来源说明。
5. 返回“已提交”或 `generating` 时只记为生成中；先查询状态，不因超时重复触发计费。
6. 成功文件先标记待验收；用户采用后才更新正式引用。失败结果和废弃候选不冒充已采用资产。
7. 当前环境没有真实媒体能力时，交付已批准的完整提示词和配置清单后停止，不静默切换供应商或模型。

## 与画布模式迁移

以后启用画布时，以本地项目状态和已采用文件为输入，通过 MCP 建立正式节点和连线；迁移不重写正文。画布导出到本地时也保留上述可读命名，不用节点 UUID 取代名称。

## 对话回执

每轮落盘后在对话框中报告：

- 本项目采用“本地目录模式”，不使用 Toonflow/MCP；
- 项目根目录的绝对路径；
- 本轮新建或修改的用户可读文件；
- 媒体处于待生成、生成中、待验收、已采用或已交付中的哪一状态；
- 当前环境缺少真实媒体工具时，明确说明只完成了文字与提示词，不得暗示已经生成媒体。
